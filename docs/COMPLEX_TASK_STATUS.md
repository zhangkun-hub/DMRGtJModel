> 本文档面向硕士层级阅读：记录"复值 DMRG 链路"这项工作的**已完成内容**与
> **下一步计划**。详细技术约定见 `docs/COMPLEX_RUN_PROTOCOL.md` 与
> `docs/PRODUCTION_COMPLEX_RERUN_PLAN.md`。

## 一、这项工作在做什么

我们现有的 DMRG 计算（归档数据）用的是**实值版本**程序：所有张量都是实数，
测量输出是标量。任务 C 的目标是把同样的体系用**复值版本**程序重算，得到
`[实部, 虚部]` 格式的复数数据——这是将来判断 **d+id 手性超导配对对称性**
的前提：手性态会破坏时间反演对称，相关物理量会携带虚部，只有复值程序才能
表达这种态。

打个比方：实值程序像"只在一条直线上移动"，复值程序像"在平面上移动"。
d+id 这种"旋转的手性态"只有在平面上才能描述。

## 二、已完成的工作（阶段 1：复值链路验收）

### 2.1 N=64 冒烟（小体系试运行）

在一个 64 格点的小体系上做了完整试运行，验证三件事：

1. 复值版程序能编译、能跑；
2. **复值程序在实值态上重现实值程序的结果**（能量逐位一致、测量虚部严格为 0）；
3. 修改前后测量程序输出逐字节兼容。

结果：全部通过（能量 −0.11183/格点，实值复值完全一致）。

### 2.2 验收口径的确定

验收时发现一个重要的数值问题：两条**各自独立收敛**的 DMRG 计算，其涨落型
观测量（如局域自旋）会差 ~10⁻⁴ 量级——这是 D=300 截断误差的自然涨落，
不是程序错误。因此定下两条验收口径：

| 数据 | 口径 |
|---|---|
| 超导配对关联（scs） | 严格数值判据（容差 1e-8）——这类量对收敛稳定 |
| 单点/两点测量（measure1） | 硬判据 = 完整性 + 虚部≈0 + 能量一致；实部差异只记录不作判据 |

### 2.3 生产编译口径验证（步骤 0）

正式生产用的是 Intel 编译器 + OpenMP（比试运行的 GNU 编译器快得多）。
在正式开跑前，先把 64 格点冒烟用 Intel 口径完整复跑了一遍——通过。

### 2.4 试点体系复跑与验收（N=200，d2_25 掺杂）

选了一个真实体系（N=200，8% 空穴掺杂）用复值程序从头重算（与归档数据
完全相同的参数和流程）。中间踩过一个坑：初版参数把空穴数算错了（写成
8 个，归档实际是 16 个），能量对不上；修正后：

| 验收项 | 结果 |
|---|---|
| 能量 | 两步绝热各阶段与归档**逐位一致**（−0.13949 / −0.13587 每格点） |
| 超导配对关联（3 个参考键） | 严格数值判据全部通过，虚部精确为 0 |
| 单点/两点测量（2 个源点） | 全部通过，虚部精确为 0 |

**结论：复值程序在生产体系上精确重现了实值归档结果，阶段 1 完成。**
复值数据存放在消费侧 `DMRG data visualization/Data_Complex/`，与归档
数据完全分开。

> 说明：按成本考虑，其余掺杂点（d1_10/d1_20/d3_25）和 N=400 体系**不重算**，
> 其复值能力由本次验收外推（推断而非直接验证）。如未来需要，随时可追加。

## 三、下一步：阶段 2——复值初态扰动

### 3.1 要解决的问题

阶段 1 复值算出的态**虚部严格为零**——因为它从实数初态出发、哈密顿量也
是实数，优化过程永远停留在实数子空间，不会自动产生手性态。这就像从直线
上出发，在平面上走，仍然只会沿着直线走。

阶段 2 的目标：**给初始态注入一个复数小扰动**，让计算有能力偏离实值
不动点：

\[
|\Psi_{\mathrm{init}}\rangle=\frac{1}{\sqrt{1+\epsilon^2}}\Big(|\mathrm{N\acute eel}\rangle+\epsilon_c|b\rangle\Big),\qquad
\epsilon_c=\epsilon\cdot\frac{1+i}{\sqrt 2}
\]

其中 |b⟩ 是一个具体的"自旋交换"构型：在原始 Néel 构型中选**一对物理
最近邻的相反自旋**互换（如 ↑↓ 换成 ↓↑）。交换不改变总粒子数和总自旋，
所以扰动仍在正确的量子数扇区内。

**本阶段只实现这条扰动链路，不判断手性态是否存在。**

### 3.2 三个物理注意事项（必须遵守）

1. **量子数守恒**：计算使用 U(1)×U(1) 对称（总粒子数 N、总自旋 Sz）。
   扰动必须是"自旋交换"这类守恒操作；单格点翻转会破坏 Sz，被排除。
2. **扰动强度 ε 要适中**：太小（如 10⁻⁶）扰动不起作用；太大（如 10）
   会破坏 Néel 初态提供的好结构。默认 ε=0.1（扰动权重约 1%），做成可调参数。
3. **初态扰动 ≠ DMRG noise**：前者只改变初始波函数；后者（`noised_vmps`
   的 noise 机制）是优化过程中帮助跳出局部极小的数值手段。两者独立。

### 3.3 源码审查的重要结论

写代码前逐文件审查了源码，几个关键事实：

- **Néel 初态的子晶格标记**与晶格类内部定义逐字符一致，无需改动；
- **物理最近邻 ≠ 链上相邻**：蜂窝晶格的最近邻链接存在晶格类的
  `nearest_neighbor_links` 成员里（含真实边界处理），扰动必须从这里取，
  不能用格点编号 (i, i+1) 代替；
- 两通道叠加 MPS 的构造**完全复用** UltraDMRG 库中已有的官方模式
  （`ExtendDirectRandomInitMps` 的骨架），API 风险最小。

### 3.4 设计要点

| 项 | 设计 |
|---|---|
| 启用方式 | 命令行 `--complex-init-eps=0.1 --complex-init-seed=12345`（不传 = 完全保持原行为） |
| ε 相位 | 固定 π/4（实虚部等分）；拒绝负数/NaN/Inf 等非法输入 |
| 扰动构型 | 真实最近邻链接中随机（固定种子，可复现）选一对自旋交换；无有效链接 → 明确报错 |
| 实值构建 | 传 ε>0 → 明确报错退出（实值程序无法表示复扰动） |
| 已有结果保护 | 运行目录已有 `./mps` 时 ε>0 → 报错退出，**绝不覆盖** |
| MPI 安全 | 所有错误统一处理：能在所有进程检查的在主进程分支前检查；主进程独占构造期间失败则广播状态码，所有进程统一退出（防死锁） |
