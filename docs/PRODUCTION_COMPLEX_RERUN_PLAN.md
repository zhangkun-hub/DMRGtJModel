## 2. 关键设计决策

1. **编译口径 = 归档口径（Intel 2022.2.0 + OpenMP）**。N=64 冒烟只验证了
   GNU 12.1.0 串行口径；复值在 Intel 口径下未验证 → 步骤 0 先用 Intel
   口径复跑 N=64 冒烟（复值构建 = 去掉 `-DRealCode=ON`，icpc 2022.2.0
   可用），通过后才进入生产步骤。
2. **从头复跑**：复值二进制读不了归档 real MPS（`Error reading file`，
   元素类型不匹配）→ 每组合从 Néel 初态从头跑（两步绝热链照归档结构）。
3. **试点先行**：试点 = **N200 d2_25**（8 洞，低档单值 1500 结构最简单），
   端到端（①→②→测量→验收）通过并经审批后再铺开其余组合。
4. **验收口径**（沿用已批准的工具与判据）：
   - scs：独立 manifest + 数值硬判据（atol=rtol=1e-8）。生产体系上两条
     独立收敛链若超差，先用 `tools/diag_measure1_diff.py` 诊断、按事实
     再定论，不擅自放宽阈值；
   - measure1：generic 口径（完整性 + 虚部≈0 + E0 一致为硬判据，
     re-diff 仅报告）；
   - E0/site：新复值日志 vs 归档日志；
   - **d3_25 基准**：verify 基准以消费侧当前实际数据为准（用户已纠错
     核对）；若归档实值测量数据缺失，降级为「虚部≈0 + E0 对比归档日志 +
     收敛检查」，并在报告中注明。
5. **数据落点**：集群新 run 目录（`run_<N>_<doping>_complex/`），归档 run
   目录与消费侧 `Data/Data_N{200,400}/` 一律不动；复值数据回传后的消费侧
   落点 = `DMRG data visualization/Data_Complex/`（与归档 Data 分离）。

## 5. 风险与纪律

- 复值从头复跑 ≠ 归档简单重算：两条独立收敛链的涨落型观测量（如 sz）
  有 D 截断误差量级差异，属预期（N=64 冒烟已实测）；
- 本方案产出"复值口径的实值态数据"与复现验收（实初态 + 实哈密顿量 →
  虚部≈0），**不产生 d+id 证据**；
- 高档 D（2000→5000）暂缓：待低档验收通过、物理需求明确后，另行追加
  审批（每组合 ~1 天）；
- **N400 不跑是范围决策**：N400 的复值能力由 N=64 冒烟 + N200 验收
  **外推**（推断，非直接验证；若未来需要 N400 复值数据，追加审批后
  单独复跑）；
- 归档数据目录、消费侧目录、协议 tag 一律不动；每步提交作业前按纪律
  审批，不自动 sbatch。
